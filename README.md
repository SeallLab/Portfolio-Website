# Portfolio-Website

This is the PLURISE Lab website hosted on vercel. Link to actual site [here](https://drdesouzasantos.com/).

The content on the website is not hosted here on the repo. It is hosted on [contentful.com](https://www.contentful.com/).
The website works by performing API request to the contentful api to get information, which is then displayed to the website.
If any changes about the actual content on the website needs to be changed then you can easily change in on the contentful platform.
Most content is hosted on contentful, some is local.
